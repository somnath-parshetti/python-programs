# Python Programs 🐍

This repository contains my Python programs and practice codes as part of my **FY BSc Data Science** learning journey.

## Programs

### 1. Factorial Number

**File:** `factorial.py`

Calculates the factorial of a given number.

**Example:**

```text
Input: 5
Output: Factorial = 120
```

### 2. Palindrome Number

**File:** `palindrome_number.py`

Checks whether a given number is a palindrome or not.

**Example:**

```text
Input: 121
Output: Palindrome
```

### 3. Reverse Number

**File:** `reverse_number.py`

Reverses the digits of a given number.

**Example:**

```text
Input: 12345
Output: 54321
```
